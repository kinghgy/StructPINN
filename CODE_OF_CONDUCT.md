# Code of Conduct / 行为准则

## English

Be respectful, evidence-driven, and constructive. Discuss code and scientific claims rather than individuals. Harassment, discrimination, personal attacks, and publication of private information are not accepted. Maintainers may edit or remove contributions that violate these expectations.

## 中文

请保持尊重、以证据为依据并提供建设性反馈。讨论应针对代码和科学结论，而非个人。不接受骚扰、歧视、人身攻击或公开他人隐私信息。维护者可以编辑或删除违反上述要求的贡献。
