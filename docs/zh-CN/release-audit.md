# 发布审计——2026-10-01

## 审计范围

本审计覆盖公开版 `StructPINN` 目录，不包括私人论文 PDF 和本地完整实验归档。

## 发布前修正

1. 将薄板直自由边有效剪力从 `Mx,x + Mxy,y` 修正为 `Mx,x + 2 Mxy,y`，y 边作对应修改，并增加制造场单元测试。公开五种子板基准全部为简支边，不受该修正影响。
2. 残差诊断改用独立固定的 `diagnostic_seed`。在共同 Sobol 网格上重新评估优化前后共十个检查点后，所有场误差统计保持不变，四阶残差平均改善由 5.33% 修正为 4.38%。
3. 已完成种子的续跑判断现在比较完整解析配置，不再只检查种子和文件是否存在。
4. 检查点改用 PyTorch `weights_only=True` 受限模式加载。
5. 历史失败/诊断配置与推荐配置分离并明确标注。
6. 排除了原始运行目录、PDF、模型二进制、本机绝对路径、缓存和个人信息。
7. 为 Navier 范围外的矩形板工况增加 NumPy Rayleigh--Ritz 交叉检查及阶次加密诊断。
8. 增加原子写入的 Adam 检查点和同环境 CPU 精确续训回归测试；正在执行的 L-BFGS 历史仍不在恢复范围内。
