# 验证与指标解释

## 梁参考解

梁预测使用独立的两节点 Euler–Bernoulli 有限元程序校核。测试还包括：

- 简支均布梁跨中挠度解析解；
- 悬臂梁端力下的端部挠度、转角和剪力解析解；
- 端部硬边界条件；
- 内部集中力处解析嵌入的剪力跳跃。

变刚度梁有限元使用单元级数值近似，属于收敛参考而不是闭式解。

## 板参考解

仅当四边均为简支且荷载为均布时提供 Navier 参考解。它通过截断双重正弦级数计算位移、曲率、弯矩和剪力合力。

其他矩形工况使用独立 NumPy Rayleigh--Ritz 能量求解器，覆盖简支、固支和直线自由边，以及均布、正弦和高斯荷载。回归测试在二者共同适用的工况下比较 Ritz 与 Navier；每次参考解还可比较配置阶次与较低阶次。这些属于有用证据，但不是证明：PINN 与 Ritz 仍共享 Kirchhoff 理论假设，而且目前仍缺少通用独立板有限元基准。

## 指标

- `relative_l2`：相对参考解的全局相对 L2 误差。
- `rmse`：绝对误差均方根。
- `max_abs`：输出网格上的最大逐点绝对误差。
- `normalized_residuals`：无量纲 PDE/边界残差的 RMS 和最大值。
- `projected_normalized_residuals`：位移导出板场的四阶平衡残差。
- `validation_reference.self_convergence`：高、低分辨率参考解之间的变化。

加权训练损失只是优化目标，不等同于精度指标。正式结果应使用多个随机种子并报告样本标准差。集中力问题应从普通剪力误差中排除不连续点，并单独检查跳跃量。

## 可复现边界

现在只有完整解析配置相同才会续用已完成种子。残差报告使用独立固定的 `diagnostic_seed`，确保模型在共同 Sobol 网格上比较，而不是沿用训练结束时的随机状态。不同平台的浮点内核和 CUDA 库仍可能产生小幅差异；PyTorch 官方也明确说明，不保证不同版本、平台或 CPU/GPU 之间逐位一致（[数值精度说明](https://docs.pytorch.org/docs/main/notes/numerical_accuracy.html)）。
