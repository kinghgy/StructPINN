# Historical ablations / 历史消融

## English

These configurations document intermediate or failed experiments:

- soft versus hard constitutive enforcement;
- boundary compatibility and anisotropic residual scaling;
- frozen-field mixed fine-tuning;
- aggressive and unanchored fourth-order displacement fine-tuning.

They are useful for reproducing negative results but are not defaults. In particular, the historical name `plate_optimized_multiseed_gpu.yaml` predates the final evaluation and did **not** pass the multi-objective acceptance gate.

## 中文

这些配置记录中间或失败实验：

- 软/硬本构约束对比；
- 边界兼容与各向异性残差缩放；
- 冻结字段的混合形式微调；
- 激进及无锚定的四阶位移微调。

它们用于复现负结果，不是默认配置。尤其是历史文件名 `plate_optimized_multiseed_gpu.yaml` 早于最终评估，实际上**没有**通过多目标验收门槛。
